# Myntra Product Data Analysis

## Project Overview
Analyzed a dataset containing 169,000+ Myntra products
using Microsoft Excel.

## Tools Used
- Microsoft Excel 2024
- Pivot Tables
- FILTER and UNIQUE
- COUNTIF and SUMIF
- Excel Charts and Slicers

## Data Cleaning
- Removed duplicate records.
- Checked missing values.
- Prepared data for analysis.

## Analysis Performed
- Brand-wise product analysis
- Product rating analysis
- Discount price analysis
- Discount percentage analysis
- Top 10 products by discount percentage

## Dashboard
Created an interactive Excel dashboard using
KPIs, charts and slicers.

## Key Learning
Improved skills in data cleaning, Excel formulas,
data visualization and dashboard development.
